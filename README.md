# Chidi's 40th · The Birthday Weekend

A single-page, mobile-first invitation + itinerary for Philadelphia, December 18–19, 2026.

Everything lives in `index.html` (no build step, no backend). Illustrations live in `images/` — see `images/README.md`.

## Sharing it as a link
Easiest: GitHub Pages → repo **Settings → Pages → Deploy from a branch**, pick the branch and `/ (root)`. You can also drag the folder onto Netlify Drop.
